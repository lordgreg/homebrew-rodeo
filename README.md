# homebrew-rodeo

Homebrew tap for [rodeo](https://github.com/lordgreg/rodeo), a dual-pane
terminal file manager with Vim-style keybindings.

## Install

```sh
brew install lordgreg/rodeo/rodeo
```

## Updates

`Formula/rodeo.rb` is bumped automatically by rodeo's `release.yml` workflow
whenever a new version tag is published. It is not meant to be edited by hand
under normal circumstances.

Currently macOS on Apple Silicon (`aarch64-apple-darwin`) only.
